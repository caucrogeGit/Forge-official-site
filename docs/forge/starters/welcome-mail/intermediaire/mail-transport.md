# Choisir un transport

Envoyer un `MailMessage` via un transport et lire le `TransportResult`. Le `FakeTransport` capture les messages pour les tests ; en vrai on choisit `ConsoleTransport`, `LogTransport`, `NullTransport` ou `SmtpTransport`.
