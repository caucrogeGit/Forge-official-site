# Bilan — niveau avancé (Vidéo)

Récapitulatif des compétences acquises au **niveau avancé** de la progression
*Bonjour Forge Vidéo*. Ce niveau **bascule vers le réel** : sonde ffprobe,
transcodage ffmpeg, et diagnostic du module.

## Ce que vous avez validé

| Palier | Compétence acquise |
|--------|--------------------|
| 1 — [Sonder une vidéo](/docs/forge/starters/welcome-video/avance/video-probe/) | Extraire les métadonnées d'un fichier via `probe_video` (ffprobe, lecture seule). |
| 2 — [Transcoder une vidéo](/docs/forge/starters/welcome-video/avance/video-transcode/) | Lancer le worker `forge video:process` (`process_video`, ffmpeg) : `uploaded → ready`. |
| 3 — [Diagnostiquer le module Vidéo](/docs/forge/starters/welcome-video/avance/video-doctor/) | Vérifier la santé du module, dont la présence de ffprobe/ffmpeg (`forge video:doctor`). |

Vous savez maintenant inspecter une source, la transcoder en MP4 via le worker et
diagnostiquer le module en exploitation.
